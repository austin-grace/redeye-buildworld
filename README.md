# redeye Build World

A small NeoForge 1.21.1 mod for the redeye modpack. It gives [World Switcher](https://modrinth.com/mod/4JiVuE1B) worlds created with seed `766337` a flat generator with a white and light grey concrete checkerboard floor, and no structures, features or mobs. Other worlds are unchanged.

Build: `./build.sh <Minecraft 1.21.1 Mojang-named jar> <worldswitcher-1.5.2.jar> <libraries dir>` (JDK 21).
